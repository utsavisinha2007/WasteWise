# ♻️ WasteWise – Household Segregation Intelligence

### Small Actions. Cleaner Planet.

**WasteWise** is a web-based household waste management and segregation platform designed to encourage responsible waste disposal practices. It helps users identify everyday waste items, understand their correct disposal categories, track household waste activities, and improve their segregation habits.

🌐 **Live Website:** https://utsavisinha2007.github.io/WasteWise/

---

## 📌 About the Project

Improper household waste segregation is a major environmental concern. Food waste, recyclable materials, hazardous waste, and general waste are often mixed together due to a lack of awareness and confusion about proper disposal methods.

WasteWise addresses this problem through an interactive web platform that makes waste segregation easier to understand and monitor.

The platform encourages users to develop better waste disposal habits through waste identification, activity tracking, segregation analysis, and personalised recommendations.

## 🎯 Project Objectives

- Promote awareness about household waste segregation.
- Help users identify the correct disposal category for common waste items.
- Encourage segregation of waste at the source.
- Track household waste disposal activities.
- Identify segregation mistakes and recurring patterns.
- Encourage environmentally responsible habits.

## ✨ Key Features

### 1. Smart Waste Classifier
Helps users identify common household waste items and suggests their appropriate disposal categories.

### 2. Household Waste Tracker
Allows users to record waste items, quantities, categories, and the bins used for disposal.

### 3. Segregation Mistake Detection
Identifies incorrect disposal practices and highlights repeated segregation mistakes.

### 4. Personalised Recommendations
Provides rule-based suggestions based on recorded household waste patterns.

### 5. Analytics Dashboard
Displays household waste information, segregation accuracy, and waste distribution.

### 6. Weekly Waste Audit
Helps users review their waste disposal activities and monitor their progress.

### 7. Segregation Challenge
Encourages users to learn correct waste segregation through interactive activities.

### 8. Environmental Impact Calculator
Helps users understand the potential environmental benefits of responsible waste management.

### 9. Disposal Guide
Provides guidance on appropriate disposal methods and possible reuse or recycling options.

### 10. Environmental Quiz and Eco-Challenges
Promotes environmental awareness through quizzes and daily sustainability challenges.

## ⚙️ How It Works

The platform follows a simple workflow:

**IDENTIFY → RECORD → ANALYSE → IMPROVE → MONITOR**

1. Identify a household waste item.
2. Check its suggested disposal category.
3. Record the waste disposal activity.
4. Analyse segregation accuracy and mistakes.
5. Follow recommendations to improve waste management habits.

## 🚀 Getting Started

You can run WasteWise locally on your computer.

### Prerequisites

- A computer with a modern web browser.
- Visual Studio Code (recommended).
- Git (optional).

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/utsavisinha2007/WasteWise.git
```

**2. Open the project folder**

```bash
cd WasteWise
```

**3. Open the project**

Open the folder in Visual Studio Code.

**4. Run the website**

Open `index.html` in your browser, or use the Live Server extension in VS Code if available.
